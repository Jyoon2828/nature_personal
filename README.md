# 나만의 자연 생물 공방 — 개인용

나뭇잎·돌 실사 질감 이미지와 그리기 도구를 이용하여 개인 작품을 만들고 PNG로 저장하는 웹앱입니다.

## 이번 버전

- 모둠 입력이나 로그인 없이 바로 작업판에서 시작
- 교사 제출·모둠 공유 기능이 없는 별도 개인용 앱
- Firebase 설정 불필요. 계정·서버 없이 브라우저에서 작업
- 투명 나뭇잎 8종·돌 8종, 클릭 및 PC 드래그 추가
- 손가락·마우스로 재료 이동, 크기 조절·회전·뒤집기·앞으로·삭제
- 붓 색·굵기, 지우개, 실행 취소·다시 실행
- 배경 선택과 자유 배경색, 투명 배경 PNG
- 생물 이름·설명을 저장 이미지에 넣기 또는 빼기
- 가로 1600픽셀 PNG 다운로드, 브라우저 임시 저장

## 사용 방법

1. 나뭇잎 또는 돌을 눌러 추가합니다.
2. 이동 도구에서 재료를 선택하여 위치와 크기·방향을 바꿉니다.
3. 그리기 도구로 생물의 눈·다리·무늬를 표현합니다.
4. 원하는 배경을 고르고 생물 이름과 표현한 특징을 입력합니다.
5. 위쪽 ‘작품 이미지 저장’을 누릅니다. PNG 파일이 다운로드됩니다.

갤럭시탭은 가로 방향을 권장합니다. 터치에서는 재료를 눌러 추가한 뒤 작업판 안에서 이동합니다. 지우개는 지나가는 위치의 재료와 그림을 함께 지우며, 선택 삭제는 선택한 재료 전체를 지웁니다.

임시 저장은 해당 기기·브라우저에만 남습니다. 공용 기기에서 새로 만들려면 ‘모두 지우기’를 누르고 이름·설명도 바꿔 주세요. 작품을 남기려면 PNG로 다운로드하세요.

## GitHub·Vercel

기존 공동 작업 앱과 별도의 GitHub 저장소와 Vercel 프로젝트에 배포하세요.

1. ZIP을 풀고 nature-personal 폴더 안의 파일과 assets 폴더를 저장소 최상위에 업로드합니다.
2. Vercel에서 해당 저장소를 Import합니다.
3. Framework Preset: Other / Build Command: 비우기 / Output Directory: .
4. Deploy합니다. Firebase 설정이나 승인된 도메인 등록은 필요하지 않습니다.

index.html을 직접 열어도 실행 가능하며, 모든 JS·이미지가 함께 있어야 합니다. 학생에게는 배포 주소 하나를 공유하면 됩니다.

## 검증

JavaScript 문법, 로컬 파일 연결, 이미지 수·투명도, 앱 상호작용의 모의 DOM 테스트를 확인했습니다. 실제 브라우저 화면 및 갤럭시탭 다운로드 동작은 이 환경에서 확인하지 못했습니다. 배포 후 재료 추가→그리기→PNG 저장을 한 번 확인하세요.

## 이미지

assets의 이미지는 실사 질감의 AI 생성 자연 재료입니다. 기존 공동 작품 앱과 같은 재료를 사용합니다. 제작 프롬프트는 ASSET_PROMPT.txt에 포함했습니다.

## 두 손가락 조작 업데이트

개인 작업판의 ‘이동’ 도구에서 나뭇잎·돌을 직접 조작할 수 있습니다.
- 한 손가락: 재료 선택과 이동
- 두 손가락 벌리기·오므리기: 확대·축소
- 두 손가락 비틀기: 회전
- 두 손가락 중심 이동: 재료 위치 이동
- 한 손가락을 떼면 남은 손가락으로 자연스럽게 이동을 이어갈 수 있습니다.

첫 손가락을 재료 위에 대고 두 번째 손가락을 작업판 안에 대세요. 이동·확대·회전을 한 동작으로 해도 실행 취소 한 번으로 되돌립니다. 그리기·지우개 도구에서는 추가 손가락으로 그림을 그리지 않습니다. 기존 크기·회전 버튼은 그대로 사용할 수 있습니다. 모둠 공동 장면에 제출된 전체 작품의 배치는 기존 한 손가락 이동 방식입니다.

GitHub의 app.js와 index.html을 이번 파일로 교체하면 됩니다. 기존 assets·Firebase 설정·Firestore 규칙은 그대로 사용합니다. 실제 갤럭시탭 터치 동작은 배포 후 확인하세요.

## 자연 재료 이미지 업데이트
돌 8종을 여백이 충분한 실사 이미지로 교체하여 가장자리 잘림과 옆 돌 조각이 섞이는 문제를 수정했습니다. 노란 자작나무 낙엽·주황 느티나무 낙엽 2종을 추가해 나뭇잎은 총 10종, 돌은 8종입니다. GitHub의 assets 폴더 전체, app.js, index.html을 교체하세요. 두 손가락 조작 기능은 유지합니다.

## 태블릿 화면 최적화
갤럭시탭 가로·세로 화면에 맞춰 작업판·재료·도구를 재배치했습니다. 재료 목록은 별도로 스크롤되며 주요 버튼은 48픽셀 이상입니다. ‘작업판 크게’ 버튼을 누르면 제목·입력란을 접어 작업 공간을 넓힙니다. 같은 위치의 ‘기본 화면’으로 돌아와 이름·설명을 입력하거나 모둠에 제출하세요. 이미지 저장은 개인용의 기본 화면 상단, 모둠용의 작업판 아래 도구에 있습니다. 새 tablet.js 파일과 index.html, style.css를 GitHub에 올리세요. 기존 두 손가락 조작과 이미지 재료는 유지됩니다. 실제 갤럭시탭 화면 검증은 아직 수행하지 않았습니다.
